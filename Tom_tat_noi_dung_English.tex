In the context of rapidly growing e-commerce in Vietnam, the demand for online
shopping has been steadily increasing, particularly in the fashion and accessories
sector. However, many small and medium-sized enterprises still lack their own
online sales platforms, relying entirely on third-party e-commerce marketplaces
such as Shopee or Lazada, which leads to a lack of control over order management,
customer data, and high commission costs. Existing e-commerce website solutions
are either overly complex, carry high operational costs, or lack domain-specific
features such as return merchandise management, shipping fee configuration by
region, or flexible role-based access control for staff.

In response to this reality, the project adopts the approach of building a
complete e-commerce web application following a client-server architecture, using
the MERN Stack (MongoDB, Express.js, React.js, Node.js) — a popular choice with
a strong ecosystem, well-suited to medium-scale projects and future scalability.

The developed solution is a retail website consisting of two main parts: a
user-facing interface that allows customers to browse products, manage their
shopping cart, make payments via VNPay or COD, view order history, and submit
return requests; and an administration panel that supports product and category
management, discount code management, role-based staff permission assignment,
user management, order management, return and exchange handling, and action
logging. The system additionally integrates Socket.IO for a real-time customer
support chatbot and sends confirmation emails via Gmail OAuth2.

The main contribution of the project is the successful development of a fully
functional e-commerce system with real-world business logic, featuring a return
merchandise workflow with a well-defined status lifecycle, a detailed role-based
permission system, and flexible shipping fee configuration — meeting the practical
operational needs of a medium-scale online fashion store.
